Aligned with UniqSuite project (e8337f3d) colors as of 2026-04-16.
- Primary: shield navy `220 65% 20%`
- Secondary: anthracite `220 15% 30%`
- Accent: copper `25 80% 50%`
- Font: Inter (headings + body)
- `eu-gradient`: navy hero gradient `220 65% 14%` → `220 15% 18%`
- `gold-gradient`: copper gradient `40 90% 55%` → `25 80% 50%`
- Gold-gradient elements use `text-accent-foreground` (white), NOT `text-primary`
- Card shadows use navy-based HSL
- Glassmorphism aesthetic with copper glow accents
